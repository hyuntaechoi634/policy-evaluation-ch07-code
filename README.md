# 제7장 정책 분석 및 평가: 실습 코드

최현태, 「제7장 정책 분석 및 평가 — 잠재결과 프레임워크에서 이중차분법까지」의 청주·청원 통합 사례를 재현하는 코드와 통계자료이다. 본문 원고와 문헌 PDF는 이 저장소에 포함하지 않는다.

## 실습의 범위

이 코드는 옛 청주시와 통합 청주시의 재정자립도 시계열을 연결하여 이중차분을 계산한다. **통합 전후의 지역 범위가 다르므로, 계산값을 통합의 인과효과로 해석하지 않는다.** 비교도시 선택과 사전 추세, 자료의 경계 변경이 해석을 어떻게 제한하는지 살펴보는 실습이다.

## 실행

저장소를 내려받은 뒤 해당 폴더에서 실행한다. Python 3.9.6에서 검증했으며, 그림 표시에는 한글 글꼴이 필요하다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python did_analysis.py
```

Windows에서는 가상환경 활성화 명령을 `.venv\Scripts\activate`로 바꾼다. 그림에는 AppleGothic, Malgun Gothic, NanumGothic, Noto Sans CJK KR 중 설치된 글꼴을 사용한다.

실행하면 기본 비교, 비교도시별 이중차분, 사전 기간 위약 비교가 출력되고 `figures/trends.png`가 생성된다. CSV가 저장소에 포함되어 있으므로 실행 중 외부 자료를 내려받지 않는다.

## 계산 결과

사전 기간은 2009–2011년, 사후 기간은 2015–2019년이며 각 기간 안에서는 연도에 같은 가중치를 준다.

| 비교도시 | 본 비교 (%p) | 사전 기간 위약 비교 (%p) |
|---|---:|---:|
| 전주시 | -2.75 | -2.308 |
| 원주시 | +1.27 | -7.483 |
| 포항시 | +4.56 | -0.725 |
| 천안시 | +0.44 | -6.075 |

위약 비교는 2005–2008년과 2009–2011년의 평균을 비교한다. 가상의 경계는 2009년이다. 기본 비교의 회귀계수는 평균의 이중차분과 일치하지만, 두 도시만을 사용한 군집 추론은 제시하지 않는다. 위약 비교 역시 유의성 검정 결과가 아닌 기술적 비교이다.

## 파일

- `did_analysis.py`: 자료 읽기, 이름 연결, 관측값 점검, 이중차분·회귀 계산, 추이 그림.
- `data/fiscal_autonomy.csv`: KOSIS에서 내려받아 보관한 2001–2025년 통계표. CP949 인코딩, 두 줄 헤더.
- `data/README.md`: 출처, 이용조건, 변수와 지역 경계에 대한 설명.
- `requirements.txt`: 실행에 필요한 패키지 버전.

## 자료 이용조건

통계자료의 작성기관은 행정안전부이며 제공 경로는 KOSIS이다. 국내 통계자료의 재사용·재배포와 출처 표기에 관한 [KOSIS 통계정보 이용지침](https://stat.kosis.kr/nsistN/kosisUseGuide.do)에 따라 출처를 명시하여 제공한다. 자세한 출처와 자료의 한계는 [자료 안내](data/README.md)에 기재하였다. 이 안내는 통계자료에 관한 것으로, 코드와 통계자료를 동일한 라이선스로 묶지 않는다.
